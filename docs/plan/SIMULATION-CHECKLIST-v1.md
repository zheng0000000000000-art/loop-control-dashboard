## 0. 지금 실측된 상태 (2026-07-28)

이 체크리스트는 추측이 아니라 아래 실측에서 나왔다.

| 잰 것 | 결과 |
| --- | --- |
| `evaluate` · 시드 2 · 40회 | `violations: 1` — `blindTransactionRoiMean` **14.479** (상한 14) |
| `tune` · 시드 5 · 400회 · 후보 100 | `solved: true`, `changed: false`, `violations: 0` |
| 통과 시 여유 | `blindTransactionRoiMean` **13.93 / 14** → **0.07** |
| 실험·포트폴리오 누적 | 이번이 **처음** (그 전까지 0건) |

**두 가지가 곧바로 드러난다.**

1. **판정이 표본 수에 따라 뒤집힌다.** 40회면 위반, 400회면 통과.
2. **탐색이 아무것도 안 바꾼다.** 기준선이 이미 통과하므로 후보 100개를 평가하고도 `changed: false`.

## 1. 게이트가 실제로 가르는가 (가장 먼저)

- [ ] **음성 사례가 있다.** 일부러 기준을 어기는 고정 사례로 돌리면 `passed: false`,
      `violations >= 1`, `failedMetrics`가 비어 있지 않다
- [ ] 어느 지표가 왜 걸렸는지 출력에 드러난다
- [ ] 통과 사례와 음성 사례를 **둘 다** 단언하는 시험이 있다

> **통과만 본 게이트는 검사가 아니라 장식이다.** 무엇을 망가뜨려야 빨개지는지 모르면
> 초록이 나와도 그것이 무엇의 증거인지 모른다.
> *(진행 중: 보드 `tsk_1d8eb8f26ff6124bd476`)*

## 2. 재현되는가

- [ ] 같은 `spec` + 같은 `seeds` + 같은 `runs` → **같은 `outputs`** (부동소수 오차 이내)
- [ ] 두 번 돌린 결과를 대조하는 시험이 있다
- [ ] `search.deterministic: true`가 실제로 지켜진다 — 껐을 때와 결과가 달라지는 것으로 확인

> 재현이 안 되면 남에게 보내도 **같은 것을 보지 못한다.** 공유·검증·회귀 전부가 여기 걸린다.

## 3. 표본 수가 충분한가 — **지금 실패 중**

- [ ] 판정을 뒤집지 않는 최소 `runs`를 **측정해서 정한다** (40 → 위반, 400 → 통과가 실측됨)
- [ ] 그 값 미만으로 돌리면 **경고가 나온다**. 조용히 통과시키지 않는다
- [ ] 경계에 붙은 지표(`blindTransactionRoiMean`, 여유 0.07)의 **분산을 함께 보고**한다

> 평균 하나로 판정하면 표본이 흔들릴 때 결론이 흔들린다.
> 명세 자신이 이미 그렇게 적어놨다 — *"평균 하나에 기대지 말고 분포와 실패율을 보고하라."*

## 4. 손잡이가 실제로 연결돼 있는가 — **미확인**

- [ ] **모든 파라미터가 최소 하나의 지표를 움직인다.** 아무것도 안 움직이는 파라미터는 죽은 손잡이다
- [ ] **모든 지표가 최소 하나의 파라미터에 반응한다.** 아무 파라미터도 못 건드리는 지표는 장식이다
- [ ] 위 둘을 파라미터 8 × 지표 8 표로 남긴다 (민감도)

> 이게 시뮬레이션판 음성 사례다. **수치를 바꿨는데 결과가 안 바뀌면 그 수치는 연결이 안 된 것**이고,
> 그러면 "될 때까지 반복"이 영원히 안 끝나거나 아무 의미 없이 끝난다.

## 5. 탐색이 일을 하는가 — **지금 무의미**

- [ ] 기준선이 **실패하는** 사례에서 탐색이 통과하는 후보를 찾는다 (`changed: true`)
- [ ] 못 찾으면 그 사실과 이유(공간 밖·해 없음)를 남긴다
- [ ] 탐색 전략(`explicit-grid`)이 공간을 실제로 덮는지 — 후보 수와 공간 크기를 비교

> 지금은 `changed: false`다. 기준선이 이미 통과하므로 **탐색이 한 번도 검증되지 않았다.**

## 6. 증거가 남는가

- [ ] 실험이 저장되고 `balance_result_read`로 다시 읽힌다 *(확인됨)*
- [ ] 포트폴리오에 결정 문서·패치·지표·차트가 쌓인다
- [ ] 결과에 **입력의 해시**가 함께 남는다 — 어떤 `spec`으로 낸 값인지 나중에 대조 가능

## 7. 사람이 정하는 것 / 기계가 하는 것

**사람만 정한다** — 자기 기준을 자기가 채점하면 그건 측정이 아니다.

- [ ] 지표의 상·하한과 가중치
- [ ] 목표 문장(`objective`)
- [ ] 제약(`constraints`)

**기계가 한다.**

- [ ] 후보 생성 · 시뮬레이션 · 점수 계산 · 반복 · 증거 저장

## 8. 레이아웃과 만나는 지점 (합류 조건)

- [ ] 시뮬레이션이 낸 값이 화면 요소에 **실제로 반영**된다
- [ ] **값을 바꾸면 화면이 바뀐다**는 것을 음성 사례로 확인 — 안 바뀌면 연결이 끊긴 것
- [ ] 같은 시드면 같은 화면

> 레이아웃은 사람이, 수치는 기계가 만든다. **둘이 만나는 자리에서만 검증이 성립한다.**
