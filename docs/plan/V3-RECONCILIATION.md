## 0. 왜 이 문서가 필요한가

`docs/plan/SIMULATION-STATUS.md` 6절을 쓸 때 **V3 계약의 존재를 몰랐다.**
그래서 이미 이름이 붙어 있는 것에 새 이름을 붙이고, V3에 있는 축을 통째로 빠뜨렸다.
**재발명 금지**(ALIGNMENT-v9)에 걸리는 자리라 대조하고 V3 어휘로 맞춘다.

**V3 는 판정표가 복원하려는 상태다.** 판정표는 V4가 V3에서 지운 것을 심판한 문서이므로,
V3에 맞추는 것과 판정표를 따르는 것은 대체로 같은 방향이다. 어긋나는 두 곳만 아래 2절에 적는다.

## 1. 일치 — 그대로 간다

| 항목 | V3 | 시뮬레이터 / 내 6절 |

| 런 길이 | 12일 | `days: 12` · 6.1 |

**마지막 둘이 크다.** 오늘 내가 도출한 두 결론(규칙 한 벌 · 생성은 옷만 입힌다)이
**V3에 이미 불변 조건으로 선언돼 있었다.** 새로 정할 것이 아니라 지킬 것이었다.

## 2. 충돌 — 판정표와 V3가 어긋나는 두 곳

### 2.1 명성 `player.fame`

- **V3**: 존재한다. 도시 지도 · 상회 · 상회 엔딩 판정 · 하루 결산 **네 씬이 읽는다.**
- **판정표 #2**: 폐기 유지 (*"획득 경로가 의뢰뿐이라 의뢰 완료 수와 동어반복"*, 사람 확인)

**폐기하면 네 씬의 표시가 바뀐다.** 판정표 판정이 사람 확인을 거쳤으므로 폐기가 우선이나,
**씬 넷을 건드리는 변경**이라 값싼 수정이 아니다. 대안은 `player.fame` 을 남기되
*상회 엔딩 판정의 입력*으로만 쓰고 획득 경로를 넓히는 것 — 그러면 동어반복이 풀린다.
**사람 결정 필요.**

### 2.2 점핑 비드 `USE_JUMP_BID`

- **V3**: 경매 세션에 행동이 있고 확인 모달도 있다.
- **판정표 #20**: 배짱패/배짱 호가 기각 (*"입력값이 자유로우면 정의상 아무 기능이 없다"*)

다만 **V3 씬 인벤토리는 최종 특별 경매에 "점핑 비드 없음 ✓"** 이라고 이미 적어놨다.
즉 V3도 결승에서는 뺐다. 판정표는 그것을 일반 경매까지 넓히자는 것이다.

**판정표 #20의 근거 중 하나는 확인이 안 됐다** — *"시뮬레이터가 이걸 파라미터로 써서 과대평가한다"*
는 코드에 없다(`circumstance*` 는 봇의 비합리 입찰이다). 나머지 근거 ①② 로 기각은 선다.

## 4. 내가 빠뜨린 것 — V3에 있는데 6절에 없다

**여기가 이 대조의 진짜 소득이다.**

| V3 | 왜 빠지면 안 되나 |
| --- | --- |
| **채권 · 담보 대출** `ISSUE_COLLATERAL_LOAN` · `REPAY_LOAN` · `bond.*` (5경로) | **자본 곡선을 직접 흔든다.** 빌릴 수 있으면 성장률 계산이 달라진다. 시뮬레이터에도 없다 |
| **정보 채널 4종** `infoChannel: 출품 순서 / 경쟁자 예산 / 출품 명세 / 수요 동향` | 내 6.3은 "감정 1회 = 태그 1개"로 뭉갰다. V3는 채널이 갈려 있다. #3이 *출품 명세* 를 폐기했으니 **3종** |
| **의뢰 5종** `contractType: 지정 / 다중 / 차익 / 절제 / 견제` | 내 6.5는 "태그 2개 조건"으로 뭉갰다. 5종이 서로 배타적이라는 것이 #11(동시 수주 상한 불필요)의 근거다 |
| **세트 예약과 기한** `reservation.deadline` | 내 6.5는 "모으면 정산"인데 V3는 **예약하고 기한 안에**다. 기한이 있으면 위험이 생긴다 |
| **숙적/뜨내기** `botIdentity: nemesis / drifter` · `rumors.nemesisStage` | 시뮬레이터의 봇 3은 전부 동질이다. 숙적이 상시라면 후반 압력의 근원이 다르다 |
| **함정 케이스** `summary.trapCase` · `trapRevealed` | 정보가 추리의 재료라는 축과 직결된다 |
| **자동 입찰** `SET_AUTO_BID` | 플레이어 입찰 정책이 하나 더 있다는 뜻 |
| **유물 전시관 · 메타** `meta.artifacts` · `meta.unlocks` | 런 간 진행. 12일 안의 밸런스와는 별개 축 |

**채권이 제일 크다.** 6절의 자본 곡선(`20,000 x 1.1435^d`)과 승급비·마감선이
**빌릴 수 없다는 전제** 위에 있는데, V3는 빌릴 수 있다.

## 5. 그래서 무엇을 한다

```
1  6절 용어를 V3 정식 이름으로 바꾼다            (값은 그대로)
2  빠뜨린 축을 백로그에 세운다                    채권 · 정보채널 · 의뢰 5종 ·
                                                 세트 기한 · 숙적/뜨내기
3  채권을 자본 곡선에 넣고 다시 푼다              6.7 · 6.8 이 흔들린다
4  충돌 둘은 사람 결정으로 올린다                 명성 · 점핑 비드
```

**2번이 끝나기 전에는 6절의 수치를 확정으로 쓰지 않는다.** 특히 채권이 들어오면
필요 성장률이 내려가므로, 지금 적힌 `15.25%` 는 **빌릴 수 없을 때의 값**이다.
